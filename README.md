# LAGRNet

LAGRNet is a monocular depth estimation network that combines learned projective transformations, graded multi-scale fusion, and sheaf-based feature propagation. It takes an RGB image and predicts a dense relative inverse-depth map.

## Method

1. **Swin backbone.** The first three Swin-Base stages extract features at strides 4, 8, and 16, with 128, 256, and 512 channels.
2. **Group-defined Feature Manifold (GFM).** A conditional MLP generates projective transformations from pooled features. Bilinear warping samples the corresponding feature views, which are combined using attention weights and a shared channel projection.
3. **Ring Convolution Layer (RCL).** Each RCL receives one feature tensor and constructs `D + 1` internal components by average pooling. A shared kernel with degree-specific output-channel masks performs Cauchy-product interactions. Batch normalization and ReLU follow each degree-wise sum, and learned softmax weights fuse the resized outputs. The default `D = 6` gives seven internal components per RCL. The network contains four RCL modules: two encoder branches and two top-down fusion blocks.
4. **Sheaf-based Module (SM).** Overlapping patches define a graph through their intersections, forming the 1-skeleton of a Čech nerve. Learned orthogonal restriction maps support two feature propagation steps and a sheaf-energy objective. Refined patch features are resized and passed to the top-down fusion path.
5. **Decoder.** Two upsampling blocks and a convolutional head produce relative inverse depth at the input resolution.

Training combines five objectives:

```text
L = L_depth + 1.0 L_pho + 0.5 L_grp + 0.1 L_sheaf + 0.01 L_sm
```

- `L_depth`: inverse-depth supervision with separate median and mean-absolute-deviation normalization of predictions and targets.
- `L_pho`: RGB reconstruction consistency using synthetic views generated by learned GFM homographies.
- `L_grp`: consistency between original and geometrically augmented predictions after spatial alignment.
- `L_sheaf`: compatibility of patch features under learned restriction maps.
- `L_sm`: edge-aware smoothness of inverse-depth predictions.

## Installation

Use Python 3.10 or newer. Run these commands from the repository root:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

For GPU training, use compatible CUDA builds of PyTorch and torchvision. The main dependencies are PyTorch, torchvision, timm, NumPy, and Pillow. Pretrained Swin initialization is enabled by default and downloads the backbone weights on first use. Set `pretrained_backbone` to `false` for random backbone initialization.

## Data Preparation

Training and evaluation use JSON Lines (`.jsonl`) manifests, with one sample per line. Paths may be absolute or relative to the manifest directory.

Example training record:

```json
{"dataset":"BlendedMVS","split":"train","image":"rgb/0001.png","depth":"depth/0001.npy","depth_scale":1.0}
```

| Field | Description |
|---|---|
| `dataset` | Dataset identifier. |
| `split` | Training or evaluation split identifier. |
| `image` | Path to the RGB image. |
| `depth` | Path to a two-dimensional depth array (`.npy`) or single-channel depth image, aligned to the original RGB image. |
| `depth_scale` | Positive multiplier that converts stored depth values to depth units. |
| `mask` | Optional validity mask at the original image resolution; nonzero entries are valid. |
| `min_depth` | Optional strict lower bound on scaled ground-truth depth. |
| `max_depth` | Optional strict upper bound on scaled ground-truth depth. |

Depth labels must contain depth values; convert disparity or inverse-depth annotations before creating the manifest. The loader retains finite positive depth values and intersects them with the optional mask and depth bounds. Each image must appear only once across the supplied manifests.

### Training datasets

The combined training manifests must contain all six identifiers below, each with `split` set to `train`:

```text
BlendedMVS, DIML, HRWSI, IRS, MegaDepth, TartanAir
```

Samples are concatenated across sources. Supply one combined manifest or repeat `--manifest` for separate files.

Training resizes the shorter image side to 518 pixels, preserves aspect ratio, and applies a random 518 × 518 crop, horizontal flipping, and color jitter. Depth and validity masks undergo the corresponding spatial transforms. Depth labels are converted to inverse depth and normalized per image. RGB inputs use mean `(0.485, 0.456, 0.406)` and standard deviation `(0.229, 0.224, 0.225)`.

### Evaluation datasets

Use these exact dataset and split identifiers:

| Dataset | Split |
|---|---|
| `KITTI` | `eigen_test` |
| `NYUv2` | `official_test` |
| `ETH3D` | `all_available_gt` |

Example evaluation record:

```json
{"dataset":"KITTI","split":"eigen_test","image":"rgb/0001.png","depth":"depth/0001.npy","depth_scale":1.0,"mask":"masks/0001.png"}
```

Encode the evaluation crop or other scoring regions in `mask`, and set `min_depth` and `max_depth` as needed. Inference preserves aspect ratio and uses the full resized image. Predictions are resized to the original ground-truth resolution for scoring.

## Configuration

Defaults are defined in [`configs/paper.py`](configs/paper.py). Pass a JSON file with `--config` to override selected fields; omitted fields retain their defaults.

### Network

| Field | Default | Description |
|---|---|---|
| `backbone_name` | `swin_base_patch4_window7_224` | Swin backbone. |
| `pretrained_backbone` | `true` | Initialize from pretrained backbone weights. |
| `K_orbit` | `4` | Number of learned GFM transformations. |
| `D_grade` | `6` | Maximum RCL degree; each module constructs `D_grade + 1` components. |
| `unified_channels` | `null` | Preserve native stage widths; an integer sets a common feature width. |
| `sheaf_dim` | `null` | Use the first backbone stage's channel count as the stalk dimension. |
| `patch_grid` | `[7, 7]` | Maximum patch positions along each spatial axis. |
| `sheaf_tau` | `0.5` | Sheaf propagation step size. |

An overridden RCL feature width must be at least `D_grade + 1`.

### Training and preprocessing

| Field | Default | Description |
|---|---|---|
| `short_side` | `518` | Resize target for the shorter side and training crop size. |
| `batch_size` | `128` | Global batch size across all processes. |
| `total_steps` | `480000` | Total optimizer updates. |
| `learning_rate` | `0.0001` | Initial AdamW learning rate. |
| `poly_power` | `0.9` | Polynomial learning-rate decay exponent. |
| `weight_decay` | `0.0001` | AdamW weight decay. |
| `augmentation_magnitude` | `0.05` | Homography perturbation magnitude in normalized image coordinates. |
| `jitter` | `0.1` | Brightness, contrast, and saturation jitter strength. |
| `seed` | `42` | Random seed. |
| `num_workers` | `4` | DataLoader workers per process. |
| `save_every` | `5000` | Checkpoint interval in optimizer steps. |
| `log_every` | `50` | Loss logging interval in optimizer steps. |

The learning rate follows `learning_rate * (1 - step / total_steps) ** poly_power`.

### Loss weights

| Field | Default |
|---|---|
| `lam_pho` | `1.0` |
| `lam_grp` | `0.5` |
| `lam_sheaf` | `0.1` |
| `lam_sm` | `0.01` |
| `gamma_sm` | `1.0` |

Depth supervision has a fixed coefficient of 1. Set an auxiliary loss weight to `0` to disable that term. `gamma_sm` controls the sensitivity of smoothness weighting to RGB edges.

For example, save the following as `train_config.json` to use a smaller global batch:

```json
{
  "batch_size": 8,
  "num_workers": 4,
  "save_every": 1000
}
```

## Training

Start training on four GPUs:

```bash
torchrun --standalone --nproc_per_node=4 train.py \
  --manifest /data/manifests/train.jsonl \
  --output runs/lagrnet
```

`batch_size` is global and must be divisible by the number of processes. The default gives 32 images per process on four GPUs.

Train on one GPU using the custom configuration above:

```bash
python train.py \
  --manifest /data/manifests/train.jsonl \
  --config train_config.json \
  --output runs/custom
```

Use `--cpu` to select CPU execution. Add `--stop-after 100` to stop at optimizer step 100 while retaining the configured learning-rate schedule. This value is an absolute target step, including when resuming.

Resume the four-GPU run:

```bash
torchrun --standalone --nproc_per_node=4 train.py \
  --manifest /data/manifests/train.jsonl \
  --output runs/lagrnet \
  --resume runs/lagrnet/latest.pt
```

For a custom run, pass the same original configuration file:

```bash
python train.py \
  --manifest /data/manifests/train.jsonl \
  --config train_config.json \
  --output runs/custom \
  --resume runs/custom/latest.pt
```

Resume requires the same configuration and manifest paths and contents. The output directory contains `config.json`, `losses.jsonl`, `latest.pt`, and numbered checkpoints such as `step_005000.pt`. A default full run ends at `step_480000.pt`.

## Inference

Predict a single image:

```bash
python inference.py \
  --checkpoint runs/lagrnet/latest.pt \
  --image /data/images/example.png \
  --output-dir outputs/predictions
```

Process a directory of PNG or JPEG images:

```bash
python inference.py \
  --checkpoint runs/lagrnet/latest.pt \
  --image-dir /data/images \
  --output-dir outputs/predictions
```

Directory processing reads images directly inside the specified directory. Use `--device cuda` or `--device cpu` to select a device; the default selects CUDA when available.

For `example.png`, inference writes:

- `example.png.inverse_depth.npy`: floating-point relative inverse-depth predictions at the original image resolution.
- `example.png.preview.png`: a min–max-normalized grayscale preview.

## Evaluation

Evaluate all three datasets:

```bash
python evaluate.py \
  --checkpoint runs/lagrnet/latest.pt \
  --manifest /data/manifests/kitti_eigen_test.jsonl \
  --manifest /data/manifests/nyuv2_official_test.jsonl \
  --manifest /data/manifests/eth3d_all_gt.jsonl \
  --diagnostics \
  --output outputs/evaluation.json
```

Evaluation fits scale and shift by least squares between raw predicted inverse depth and ground-truth inverse depth on each image's valid scoring pixels. It reports AbsRel, SqRel, RMSE, log-RMSE using the natural logarithm, and threshold accuracies at `1.25`, `1.25²`, and `1.25³`.

Metrics are averaged per image within each dataset. When all three datasets are supplied, the output also includes their equally weighted mean. The JSON contains per-image scores, valid-pixel counts, alignment parameters, and the selected evaluation settings.

`--nonpositive` controls aligned predictions that are zero or negative:

| Value | Behavior |
|---|---|
| `error` | Stop evaluation if an aligned prediction at a valid scoring pixel is nonpositive; this is the default. |
| `exclude` | Exclude nonpositive aligned predictions from all metrics. |
| `clamp` | Clamp aligned predictions to at least `1e-6` before computing metrics. |

Alignment is fitted before applying this policy. The output records the policy and each image's positive-prediction fraction.

With `--diagnostics`, evaluation also exports learned sheaf energy and ordinary graph energy from the final patch features. Each value is one half of its corresponding edge-residual sum of squares, divided by the number of patches.
